## 📌 ফিচারসমূহ (Key Features)

- 💳 **টপ পেমেন্ট চ্যানেল:**
  - **bKash:** `01834093932`
  - **Rocket:** `018927170930`
  - **WhatsApp:** `01892717093`
  - **Facebook:** Offside Exports
- 📊 **লাইভ হিসাব সামারি (KPI Cards):** মোট বিক্রি (Total Bill), মোট আদায় (Received), মোট বাকি (Due), কাস্টমার সংখ্যা।
- 🟢 **স্ট্যাটাস ব্যবস্থাপনা:**
  - **পরিশোধ (Paid):** সবুজ ব্যাজ
  - **আংশিক পরিশোধ (Partial):** হলুদ ব্যাজ (বাকি টাকার হিসাবসহ)
  - **বাকি আছে (Due):** লাল ব্যাজ
- 💰 **টাকা জমা (Quick Pay):** যেকোনো কাস্টমারের নামের পাশে `+` চাপলে নতুন টাকা জমার সাথে সাথে বাকি টাকা নিজে নিজে কমে যাবে।
- 💾 **ডাটাবেজ সুরক্ষা (Permanent Storage):**
  - **SQLite Database (`offside_accounts.db`):** হার্ডডিস্কে সরাসরি ডাটা সেভ থাকে।
  - **Browser IndexedDB:** ব্রাউজার বন্ধ করলেও ডাটা ডিলিট হয় না।
- 📥 **এক্সেল ও ব্যাকআপ:** ১ ক্লিকে Excel (CSV) এবং JSON Backup ডাউনলোড।
- 💬 **WhatsApp রিমাইন্ডার:** ১ ক্লিকে কাস্টমারকে বাকি টাকার হিসাব ও পেমেন্ট নাম্বারসহ মেসেজ পাঠানোর সুবিধা।
- 🧾 **মানি রসিদ (Receipt):** কাস্টমারকে প্রিন্ট করে দেওয়ার মতো ক্যাশ মেমো / রসিদ তৈরি।

## 🚀 কীভাবে চালাবেন (How to Run)

### উপায় ১: Mac-এ ১ ক্লিকে চালু (Recommended)
`start_offside_app.command` ফাইলে ডাবল-ক্লিক করুন। সাথে সাথে সার্ভার চালু হয়ে ব্রাউজারে `http://localhost:5000` ওপেন হবে।

### উপায় ২: সরাসরি ব্রাউজারে
`index.html` ফাইলে ডাবল-ক্লিক করে যেকোনো ব্রাউজারে (Chrome/Safari) ওপেন করুন।

### উপায় ৩: পাইথন সার্ভার কমান্ড
```bash
python3 server.py 5000
```
এরপর ব্রাউজারে যান: `http://localhost:5000`
